# Structured PDF reference

What each corpus PDF states about itself, as data. Generated by
`PdfReferenceExtractor`; regenerate with:

```bash
UPDATE_PDF_REFERENCE=1 dotnet test tests/PromptResponse.Rendering.Pdf.Tests
```

## Why this exists

APR is not a visual format, so a conversion cannot be checked by looking at it.
It is checked structurally: are all the fields here, which are missing, which
text belongs to which field, and are the questions asked in the right order.
Answering those needs the PDF's content as data — which is this.

Each field and each line of text carries its **geometry**, so a person or a
later process can find it on the page. A reference with no coordinates can say a
field is missing but never where to go look.

## What tier each part is

The PDF is still the source of truth; this is its extracted form, and how far
that extraction can be trusted differs by part.

| part | tier | why |
| --- | --- | --- |
| field list, types, option counts | **1** | the PDF states them |
| widget rectangles, page sizes | **1** | stated |
| line text and its box | **1** | stated, subject to the grouping note below |
| a field's `label` (`/TU`) | **1** where present | the form author's own words — only ~34% of fields have one |
| `order` on fields and lines | **inferred** | geometric, see below |

## The two judgement calls, stated plainly

**Line grouping.** Words are grouped by shared baseline, then split where the
horizontal gap exceeds three times that line's own median word gap (minimum
8pt). Without the split, W-9's header produced `"Form W-9 Give form to the"` —
two columns joined into a sentence nobody wrote, which would then read as a
label for whatever field sits nearby. The split cut lines spanning most of the
page width from 29% to 8%.

**Reading order.** Derived geometrically: by page, then down, then across. Right
for a single-column form, approximate for a multi-column one. It is recorded
because order is a real property a conversion must get right — a form asked
backwards is wrong even when every field is present — but it is review material,
not an oracle to grade against unchecked.

## What is deliberately absent

**Which line labels which field.** That pairing is exactly what the converter is
graded on, so deriving it here with the same kind of logic would be grading the
converter against itself. This file supplies the evidence; the verdict belongs
to a source that is independent of the thing under test.

`ct-dmv-a25.json` has zero lines — it is a scan with no text layer, and that is
the correct extraction, not a failure.
